# Tipografías

Incorporar aquí los archivos originales autorizados de Montserrat y Another Danger junto con sus licencias. No se distribuyen archivos de fuentes en esta fase.

La interfaz declara estas familias con respaldo local en `src/app/globals.css`. Al recibir los archivos, usar `next/font/local` desde `src/app/layout.tsx` y conectar sus variables a `--font-sans` y `--font-display`. Evitar referencias a archivos inexistentes y descargas de fuentes durante la compilación.
